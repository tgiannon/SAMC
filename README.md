# SAMC Prep — Expanded Prototype

A mobile-friendly prototype for Sergeant Audie Murphy Club board preparation.

## Expanded content
- 100+ source-tagged study questions
- SAMC history and program
- SAMC crest and medallion
- Audie Murphy biography and military timeline
- Audie Murphy awards, films, songs and Medal of Honor action
- Army history dates included in the Fort Lee guide
- Board preparation and reporting procedures
- Current TRADOC board-domain references from TRADOC Form 600-14-4 (Aug 2023)
- Situational leadership practice
- Army Values / leadership concepts
- Adaptive quiz selection and local progress tracking
- Category-level readiness dashboard

## Source hierarchy
Primary:
1. TRADOC Regulation 600-14
2. TRADOC Form 600-14-4 (Aug 2023)
3. U.S. Army Garrison Fort Lee SAMC materials
4. Official Audie Murphy Research Foundation SAMC material

Supplemental:
- Army doctrine/leadership concepts

## Important content-control rule
The Fort Lee study guide was created December 2, 2021. It contains useful board preparation material but is not automatically current. Items from that guide that are time-sensitive or contain known discrepancies are explicitly flagged in the question source. Before a Soldier relies on a question for an actual board, the app should compare it against the current regulation and local chapter guidance.
